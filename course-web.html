Кому подойдёт

  • Тем, кто хочет самостоятельно собрать и опубликовать небольшой сайт.

Что получится в конце

Адаптивный сайт с семантической разметкой, базовым JavaScript и опубликованной рабочей версией.

Как проходит обучение

Учебный ритм собран вокруг коротких объяснений, самостоятельной практики и понятной проверки результата.

  1. 01

    Материал

    Изучаете HTML, CSS и JavaScript на коротких примерах с пояснением логики.

  2. 02

    Практика

    Собираете страницы своего сайта и проверяете их на разных ширинах экрана.

  3. 03

    Обратная связь

    В групповом формате разбираете ключевые технические решения и ошибки.

Программа
курса

Модули ведут от первой задачи к готовому учебному проекту.

  1. 01

    HTML и семантика

    Собираете понятную структуру страницы и выбираете корректные HTML-элементы для содержания.

  2. 02

    Современный CSS

    Настраиваете сетку, адаптивные размеры и состояния элементов без копирования чужих шаблонов.

  3. 03

    JavaScript для интерфейса

    Добавляете небольшие сценарии: меню, раскрывающиеся блоки или проверку простого действия.

  4. 04

    Публикация и проверка

    Проверяете сайт на телефоне и публикуете версию, которую можно открыть по ссылке.

Что потребуется для обучения

  • Ноутбук или компьютер
  • Современный браузер
  • Редактор кода, например VS Code
